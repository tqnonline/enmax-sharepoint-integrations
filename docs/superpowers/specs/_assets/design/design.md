# ENMAX Brand Colour Palette

## Overview

The ENMAX colour system comprises three primary brand colours, a supporting neutral palette, and semantic colours for system states. This palette is designed to project authority and reliability whilst remaining approachable and energetic—reflective of ENMAX's role as a forward-thinking energy utility serving the Calgary region and beyond.

The system supports both **light** and **dark** theme implementations, ensuring optimal readability and visual harmony across user preferences, time of day, and device capabilities.

---

## Theme Strategy

### Light Theme (Default)
Used as the primary interface theme for day-time usage, digital applications, and contexts requiring clear visual hierarchy and maximum legibility. The light theme establishes brand presence through bold, saturated colours against clean backgrounds.

### Dark Theme
Provides a comfortable, lower-luminance experience for evening usage, accessibility needs, and power-conscious devices. Dark theme desaturates and lightens primary colours whilst maintaining brand recognition and hierarchy.

## Accessibility Considerations

### Light Theme Contrast Ratios

- **Cinnabar on White:** 7.2:1 (AAA compliant)
- **Chathams Blue on White:** 9.1:1 (AAA compliant)
- **Slate Gray on White:** 8.3:1 (AAA compliant)
- **Marzipan on White:** 2.1:1 (AA compliant for large text only)

### Dark Theme Contrast Ratios

- **Cinnabar (Dark) on Dark Charcoal:** 5.8:1 (AA compliant)
- **Chathams Blue (Dark) on Dark Charcoal:** 9.2:1 (AAA compliant)
- **Dark Text on Dark Charcoal:** 12.1:1 (AAA compliant)
- **Marzipan (Dark) on Dark Charcoal:** 5.2:1 (AA compliant for large text)
- **Success (Dark) on Dark Charcoal:** 6.8:1 (AA compliant)
- **Error (Dark) on Dark Charcoal:** 5.2:1 (AA compliant)

### Accessibility Guidance

Never rely on colour alone to convey information. Pair colour choices with text labels, icons, or patterns. 

For light theme: Marzipan backgrounds with body copy require Slate Gray text (#475569) to maintain legibility.

For dark theme: All primary colours have been recalibrated to ensure minimum AA compliance against dark backgrounds. When using Marzipan (Dark) with body copy, always use Dark Text (#E2E8F0) for sufficient contrast.

Semantic colours (green/red) should always be accompanied by supporting icons or text to assist users with colour blindness. Consider using additional visual indicators beyond colour—checkmarks for success, exclamation marks for errors, etc.

### React Implementation with Theme Toggle

```jsx
import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const [isDark, setIsDark] = useState(false);

  const toggleTheme = () => setIsDark(!isDark);

  const colors = {
    light: {
      primary: '#E1393E',
      secondary: '#0F487A',
      accent: '#F7DB9C',
      bg: '#F8FAFC',
      text: '#475569',
    },
    dark: {
      primary: '#FF6B73',
      secondary: '#5BA3E8',
      accent: '#E8C76A',
      bg: '#1E293B',
      text: '#E2E8F0',
    },
  };

  const theme = isDark ? colors.dark : colors.light;

  return (
    <ThemeContext.Provider value={{ isDark, toggleTheme, theme }}>
      <div style={{ backgroundColor: theme.bg, color: theme.text }}>
        {children}
      </div>
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  return useContext(ThemeContext);
}

// Usage in Component
function Button() {
  const { theme } = useTheme();
  return (
    <button style={{ backgroundColor: theme.primary, color: 'white' }}>
      Click me
    </button>
  );
}
```

## Design Principles

### Hierarchy Through Colour

The ENMAX palette creates natural visual hierarchy without requiring size or weight alone. Cinnabar draws the eye first, Chathams Blue grounds information, and Marzipan punctuates features.

### Restraint and Confidence

This is not a system designed for constant colour rotation. The strength lies in consistent, confident deployment of a tight palette. Overuse dilutes impact.

### Complementary Opposition

Cinnabar and Chathams Blue sit in complementary colour space—they work together through visual contrast. Marzipan acts as a mediator, preventing the palette from feeling too aggressive.

### Energy and Trust

The warm crimson alongside the cool, deep blue creates psychological balance: energy tempered by reliability, innovation grounded in expertise.

## Theme Switching & Best Practices

### When to Use Light Theme
- Default interface for day-time usage
- High-luminance environments (bright offices, outdoors)
- Formal, professional presentations
- Print-friendly digital interfaces
- Accessibility for users with light-sensitive conditions
- Standard web applications and dashboards

### When to Use Dark Theme
- Evening and night-time usage
- Low-light environments (bedrooms, dark offices)
- Power-conscious mobile devices
- Accessibility for users with light-sensitive conditions or astigmatism
- Modern application interfaces requiring contemporary aesthetics
- Extended viewing sessions requiring reduced eye strain

### Implementation Best Practices

**Respect User Preference:**
Always respect the `prefers-color-scheme` media query. Implement a toggle allowing users to override system preference if desired.

```css
@media (prefers-color-scheme: dark) {
  /* Dark theme styles */
}
```

**Smooth Transitions:**
When switching themes, use CSS transitions to avoid jarring visual shifts.

```css
* {
  transition: background-color 0.3s ease, color 0.3s ease;
}
```

**Persistent Preference:**
Store user theme preference in localStorage to maintain consistency across sessions.

```javascript
localStorage.setItem('theme-preference', isDark ? 'dark' : 'light');
const saved = localStorage.getItem('theme-preference');
```

**Contrast Verification:**
Always verify contrast ratios when customising colours. Use tools like WCAG Contrast Checker to ensure compliance.

**Colour Meaning Consistency:**
Red always means error, green always means success—regardless of theme. Semantic meaning should never change between light and dark modes.

## Do's and Don'ts

### ✓ Do

- Use Cinnabar for primary actions and brand moments (light), switch to Cinnabar (Dark) #FF6B73 automatically in dark mode
- Pair Chathams Blue with body copy and supporting content across both themes
- Deploy Marzipan as a deliberate accent in light mode; use desaturated Marzipan (Dark) in dark theme
- Maintain sufficient contrast for legibility in both light and dark modes (WCAG AA minimum, AAA preferred)
- Use semantic colours (green/red) for system states alongside text/icons, adjusting for each theme
- Test colours in context across different devices, lighting conditions, and both themes
- Respect user's system preference for colour scheme and provide manual override
- Use CSS variables for theme switching to avoid colour duplication
- Verify contrast ratios for every colour combination in both themes
- Provide smooth transitions when switching between themes

### ✗ Don't

- Use the same colour value across both themes—light theme colours appear oversaturated in dark mode
- Mix all three primary colours equally across a single interface in either theme
- Apply colour without semantic meaning—colour should always serve purpose
- Forget that approximately 1 in 12 men and 1 in 200 women have colour blindness
- Use Cinnabar in high-frequency patterns; reserve it for moments of emphasis
- Deviate from the palette without explicit design system governance
- Assume the light theme palette works unchanged in dark mode
- Forget to test both themes with actual users and accessibility tools
- Use pure white (#FFFFFF) as background in dark theme—use Dark Charcoal (#1E293B) instead
- Invert colours automatically without manual adjustment—programmatic inversion rarely produces accessible results
- Change semantic colour meaning between themes (e.g., using red for success in one theme, error in another)
- Neglect to provide theme toggle for users who need to override system preference
